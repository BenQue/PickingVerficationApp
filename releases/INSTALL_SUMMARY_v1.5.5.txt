核心改进
===============================================

✅ HTTP 400错误消息显示优化
   - 改进前: 显示技术性的DioException信息

✅ 集中配置管理系统
   - 新增AppConfig配置类
   - 统一管理员工ID和工作中心代码

✅ 增强的错误诊断功能
   - 详细的API请求/响应日志
   - HTTP 400专门诊断信息
   - 智能错误消息提取

===============================================
安装方法
===============================================

方法1: ADB命令行安装
---------------------
adb install -r releases/warehouse-app-v1.5.5-build45.apk

方法2: 手动安装
---------------------
1. 复制APK到设备
2. 打开文件管理器
3. 点击APK安装
4. 允许从此来源安装

===============================================
验证安装
===============================================

1. 启动应用
2. 点击右上角员工信息按钮
3. 确认版本号显示为: V1.5.5

===============================================
重要提示
===============================================

⚠️ 当前配置:
   - 员工ID: operator
   - 工作中心: WC001
   - 调试日志: 启用

⚠️ 如遇HTTP 400错误:
   1. 查看日志: adb logcat -s flutter
   2. 记录错误消息
   3. 查看文档: docs/TROUBLESHOOTING_HTTP_400.md

⚠️ 生产环境部署:
   需要关闭调试日志 (enableApiDebugLogging = false)
