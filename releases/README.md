- **发布日期**: 2025年12月12日

### 主要功能
- 🆕 **按物料查询库存** - 查看物料所有批次库存分布 (v1.7.0 新增)
- 🟣 电缆下架到线边库 (2200-100)
- 🟠 电缆上架或库位转移
- 🟢 库存扫码查询
- 🔵 合箱校验功能
- 📥 电缆入库

### v1.7.0 新特性
- ✅ 新增按物料号码查询库存功能
- ✅ 显示物料所有批次库存分布
- ✅ 优化物料查询界面布局
- ✅ 改进扫码输入兼容性
