# 仓库拣货验证 App - 版本 1.5.3 发布说明

**发布日期**: 2025年11月10日
**版本号**: 1.5.3 (Build 43)
**类型**: Bug修复版本
**更新重要性**: 推荐更新

---

## 📝 版本概述

本次更新主要修复了合箱校验功能中 HTTP 400 错误信息显示不清晰的问题。用户现在可以看到服务器返回的详细错误信息，而不是通用的"HTTP 400"错误代码，大大改善了用户体验和问题排查效率。

---

## ✨ 主要改进

### 1. 修复 HTTP 400 错误信息显示问题

**问题描述**:
- 在合箱校验时，当出现订单不存在、订单状态不符合等业务逻辑错误时
- 用户只能看到通用错误："操作失败！获取工单详情失败：HTTP 400"
- 无法了解具体的错误原因，影响问题排查

**修复效果**:
- ✅ 现在显示服务器返回的详细错误信息
- ✅ 例如："扫码出错：未查询到订单信息"
- ✅ 或："该工单已完成验证"
- ✅ 帮助用户快速了解问题原因并采取正确的操作

**技术细节**:
- 优化了 HTTP 客户端配置，正确处理 4xx/5xx 错误响应
- 改进了错误消息解析逻辑
- 增强了网络请求调试日志

### 2. 增强调试能力

**改进内容**:
- 添加了详细的网络请求日志
- 记录请求 URL、参数、响应状态码和数据
- 便于生产环境问题排查和技术支持

**日志示例**:
```
=== 开始获取工单详情 ===
订单号: 123456789
请求URL: http://10.163.130.173:8001/api/WorkOrderPickVerf?orderno=123456789
响应状态码: 400
响应数据: {"isSuccess":false,"message":"扫码出错：未查询到订单信息","data":null}
服务器返回错误消息: 扫码出错：未查询到订单信息
```
