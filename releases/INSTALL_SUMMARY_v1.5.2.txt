安装步骤
--------
1. 连接设备
   adb devices

2. 安装APK
   adb install -r releases/warehouse-app-v1.5.2-build42.apk

3. 验证版本
   adb shell dumpsys package com.example.picking_verification_app | grep versionName
   # 预期输出: versionName=1.5.2

4. 启动应用并验证
   - 点击右上角员工信息按钮
   - 确认显示 "V1.5.2"
