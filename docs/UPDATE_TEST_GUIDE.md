# 自动更新功能测试指南

## 📦 准备工作

### 服务器端文件
需要将以下文件部署到 HFS 服务器 (`10.163.130.173:8000`)：

```
C:\HFS\                                    # HFS 服务器根目录
├── version.json                           # 版本配置文件
└── warehouse-app-v1.5.1-build41.apk      # v1.5.1 安装包 (78 MB)
```

### PDA 设备准备
- ✅ 已安装 v1.5.0 版本
- ✅ 连接公司内网 WiFi
- ✅ 可以访问 `10.163.130.173:8000`

## 🔧 故障排查

### 问题：未检测到更新

**排查步骤：**
```bash
# 1. 检查服务器连接
curl http://10.163.130.173:8000/version.json

# 2. 验证 version.json 内容
# 确认 versionCode 为 41

# 3. 检查应用日志
adb logcat | grep -i "update"

# 4. 验证当前版本
adb shell dumpsys package com.example.picking_verification_app | grep versionName
```

### 问题：下载失败

**排查步骤：**
```bash
# 1. 测试 APK 文件可访问性
curl -I http://10.163.130.173:8000/warehouse-app-v1.5.1-build41.apk

# 2. 检查文件大小
# 应该显示约 78 MB

# 3. 尝试手动下载
curl -O http://10.163.130.173:8000/warehouse-app-v1.5.1-build41.apk
```

### 问题：安装失败

**可能原因：**
1. 签名不匹配（使用了不同的密钥）
2. 权限不足（未开启"未知来源"）
3. 存储空间不足
4. APK 文件损坏

**解决方法：**
- 检查签名证书
- 开启安装权限
- 清理存储空间
- 重新下载 APK
