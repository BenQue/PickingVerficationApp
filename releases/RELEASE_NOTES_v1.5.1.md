# Release Notes - v1.5.1 (Build 41)

**Release Date:** 2025-11-04
**APK Size:** 78 MB
**Purpose:** 测试自动更新功能

## 📋 版本说明

这是一个**测试版本**，主要用于验证 PDA 手持终端上的自动更新功能是否正常工作。

## ✅ 测试目的

1. **验证自动更新检测**
   - PDA 设备上已安装 v1.5.0
   - 启动应用时应自动检测到 v1.5.1 新版本
   - 显示更新提示对话框

2. **验证下载功能**
   - 点击"立即更新"按钮
   - 观察下载进度条是否正常显示
   - 验证进度百分比和文件大小显示

3. **验证安装流程**
   - 下载完成后自动打开安装界面
   - 确认可以成功安装新版本
   - 验证安装后版本号为 v1.5.1

4. **验证手动检查更新**
   - 点击右上角员工信息按钮
   - 点击"检查更新"按钮
   - 验证可以手动触发更新检查

## 🔍 问题排查

### 问题 1：未弹出更新对话框
**可能原因：**
- 网络连接问题
- 更新服务器未运行
- version.json 未正确更新

**排查步骤：**
```bash
# 1. 检查网络连接
ping 10.163.130.173

# 2. 检查服务器是否运行
curl http://10.163.130.173:8000/version.json

# 3. 检查返回内容
# 应该显示 versionCode: 41
```

### 问题 2：下载失败
**可能原因：**
- 网络不稳定
- APK 文件未上传到服务器
- 文件路径错误

**排查步骤：**
```bash
# 检查 APK 文件是否存在
curl -I http://10.163.130.173:8000/warehouse-app-v1.5.1-build41.apk
# 应该返回 200 OK
```

### 问题 3：安装失败
**可能原因：**
- 未授予安装权限
- 签名不匹配
- 存储空间不足

**解决方法：**
- 检查"未知来源"安装权限
- 确保使用相同的签名密钥
- 清理设备存储空间
