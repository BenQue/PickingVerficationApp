## 新功能

### 📦 按物料号码查询库存
新增通过物料号码查询库存的功能，方便用户快速了解某物料所有批次的库存分布情况。

**功能特点：**
- 在库存查询页面新增"按物料查询"模式切换
- 输入物料号码（如：806823）后按回车查询
- 显示该物料所有批次的库存列表
- 汇总显示：批次总数、当前库存总数量
- 每个批次详情显示：批次号、条码、库位、库存数量

---

## 优化改进

### 🎨 物料查询界面优化
- 精简物料信息卡片，减小高度占用
- 批次详情布局优化，条码和库位信息合并显示
- 整体界面可滚动，方便查看多批次库存
- "剩余数量"改为更直观的"库存数量"

### ⌨️ 扫码输入兼容性改进
- 修复 `TextInputType.none` 导致部分 PDA 扫码枪无法输入的问题
- 改用 `TextInputType.text` 配合 `SystemChannels` 控制软键盘
- 物料查询输入框默认不弹出软键盘，与条码查询保持一致

---

## 技术改进

### 代码变更
- `stock_query_screen.dart`: 新增物料查询模式和结果展示
- `barcode_input_field.dart`: 优化键盘类型设置，提升硬件扫码枪兼容性
- `line_stock_bloc.dart`: 新增物料查询事件处理
- `line_stock_remote_datasource.dart`: 新增物料查询 API 调用

### API 新增
- `GET /api/LineStock/byMaterialCode` - 按物料号码查询库存
